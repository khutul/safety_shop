# safety_pos_qpay

Odoo POS-д QPay QR төлбөрийн аргыг нэмнэ. Кассчин «QPay (QR)» аргыг сонгоход
захиалгын яг дүнгээр QPay v2 API-аар нэхэмжлэх үүсгэж, QR-ыг дэлгэц дээр
харуулна; POS нь QPay-г 3 секунд тутам шалгаж, төлбөр төлөгдмөгц автоматаар
баталгаажуулна. QPay-ийн мерчант эрхийг System Parameters (qpay.*)-аас авдаг.

**Тохиргоо:** Суулгасны дараа POS → Тохиргоо → Төлбөрийн арга → шинэ арга
үүсгэж, «Use a Payment Terminal = QPay (QR)» сонгоод POS-д холбоно.
